Hello! Welcome to my second full-length self-project. This one is called SupportTech.ai!

I want to create my own AI agent that provides me with only the very best technical knowledge whenever I have questions. I plan to have a fully-functioning UI with a well-designed website that can remember previous questions you had. I want to be involved in every step of the AI training process, even fine-tuning if my hardware allows for it. I will also implement PyTorch in some way, since I want to get familiar with how it works since it is the backbone of the transformer architecture.
