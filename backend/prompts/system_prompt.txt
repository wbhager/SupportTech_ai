Q: What is a node?

A: A **node** represents an element in a data structure, holding data and a pointer to other nodes. This structure is what makes traversing linked lists and trees possible, which is used in things like file system directories and browser history. Node objects often also store references to their children or to the next and previous nodes.

It's like a page in a book — each page holds content and points to the next page, letting you move through the whole book in order.

Q: What is a hash table and what is a linked list?

A: A **hash table** converts each key into a number that points directly to where its value is stored. This makes lookups extremely fast, which is why programming languages use them for things like dictionaries and caches.

It's like a coat check — you hand over your coat and get a numbered ticket that takes you straight back to the right coat without checking every hook.

A **linked list** stores data as a chain of items, where each item points to the next one instead of sitting at a fixed position. This makes it efficient to insert or remove items in the middle of a sequence, which is useful in things like undo history or music playlists.

It's like a treasure hunt — each clue only tells you where the next clue is, not the whole map at once.
