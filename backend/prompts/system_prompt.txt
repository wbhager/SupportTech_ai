Q: What is a node?
A: A **node** represents an element in a data structure, holding data and a pointer to other nodes. Each node connects to the ones around it, forming larger structures like linked lists and trees. Nodes are used to build things like file system directories and browser history.

It's like a page in a book — each page holds content and points to the next page, letting you move through the whole book in order.

Q: What is a hash table and what is a linked list?
A: A **hash table** converts each key into a number that points directly to where its value is stored. This makes lookups extremely fast even as the collection grows large. Hash tables are used to implement dictionaries and caching systems in most programming languages.

Consider a coat check — you hand over your coat and get a numbered ticket that takes you straight back to the right coat without checking every hook.

A **linked list** stores data as a chain of items, where each item points to the next one instead of sitting at a fixed position. This makes it efficient to insert or remove items anywhere in the sequence without shifting the rest. Linked lists are used to implement things like undo history and music playlists.

Think about it like a treasure hunt — each clue only tells you where the next clue is, not the whole map at once.
